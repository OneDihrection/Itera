# Balancing fruit source

Apple model: Kenney, Food Kit 2.0 (CC0).
Original page: https://kenney.nl/assets/food-kit
Downloaded 4 November 2026 from the author-uploaded mirror: https://opengameart.org/sites/default/files/kenney_food-kit.zip

`apple.glb` and `License.txt` are unmodified upstream files. The bundled `balance-apple.png` is a transparent 512×512 Blender render of that model. It is rendered offline; the app needs no network or runtime 3D model loading for the fruit. Basket artwork is native SwiftUI. The runtime includes only the rendered PNG.
