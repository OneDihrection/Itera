# Font resources

Poppins fonts and the unchanged OFL.txt were copied from the supplied Poppins directory. Original authorship and license are retained.

## Plus Jakarta Sans

The finger exercise interface uses Plus Jakarta Sans Regular and Bold from [Tokotype](https://github.com/tokotype/PlusJakartaSans/tree/master/fonts/ttf). Original font binaries are unchanged. The SIL Open Font License is preserved in PlusJakartaSans/PlusJakartaSans-OFL.txt. Typography maps semantic weights to these two bundled faces. Existing Poppins binaries are retained for compatibility.
