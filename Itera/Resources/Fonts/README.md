# Font resources

## Plus Jakarta Sans

All app typography uses Plus Jakarta Sans Regular and Bold from [Tokotype](https://github.com/tokotype/PlusJakartaSans/tree/master/fonts/ttf). Original font binaries are unchanged. The SIL Open Font License is preserved in PlusJakartaSans/PlusJakartaSans-OFL.txt. Typography maps semantic weights to these two bundled faces.
